# TCS Financial Data Analysis – Yuvaintern Internship

Professional financial-data-analysis project covering Weeks 2–4 of a Junior Financial Data Analyst internship workflow.

**Companies:** TCS, Infosys, HCLTech, Wipro  
**Historical panel:** 13 common quarters, Q1 FY24–Q1 FY27, 52 company-quarter observations  
**Workflow:** Data collection & cleaning → Visualization & reporting → Forecasting & predictive modelling

## Weeks
- Week 2 — Financial Data Collection & Cleaning
- Week 3 — Financial Data Visualization & Reporting
- Week 4 — Financial Forecasting & Predictive Modelling

The repository contains the reports, cleaned data, Python code, notebooks, charts, model outputs, and supporting files used across the three weeks.

This is an educational internship simulation using public information. It is not investment advice.
